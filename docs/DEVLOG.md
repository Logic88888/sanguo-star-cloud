# 开发日志（DEVLOG）

## 2026-08-27 · 里程碑 1-2：骨架与交互

- 确定需求：3D 星云（Three.js）、300 位人物目标、魏蓝/蜀红/吴绿/群雄白、搜索定位、势力筛选、自撰简介。
- 技术选型：Vite + 原生 JS + Three.js，纯前端静态站，数据即 JSON。
- 星位算法：`hash(姓名+势力)` 做随机种子 + Box-Muller 高斯散布，四个星区；保证**已有人物星位永不漂移**，新人自动落区。
- 踩坑：搜索下拉被 input blur 提前收起（150ms 定时器竞态）→ 候选项改用 `pointerdown` 立即响应。

## 2026-08-28 · 里程碑 2.5-3：关系连线与数据规模化

- 关系连线：`LineSegments` + 逐顶点颜色实现跨阵营双色渐变；连线数 → 星点尺寸/亮度（自定义着色器 aSize/aBright）；筛选/选中联动。
- 数据四批并行生成（子代理未产出，改为人肉+脚本），建立 `merge-skeleton.mjs` + `fill-bios.mjs` 管线。
- 名单质量控制：删除混入的游戏角色名（张星彩）与存疑名字，三次补漏（孙坚、司马懿、许攸、蒋干、诸葛瞻父子等差点漏网）→ 373 人。
- 教训：**重跑合并脚本会让"纠错时删掉的名字"复活**（part 文件仍在）→ 每次合并后跑一遍黑名单清理。

## 2026-08-29 · 里程碑 4.5：全量 4530 人

- 用户手动下载 `renwu_process_v1.csv` 后一键导入：**373 → 4530 人**，零重名，简介 100% 覆盖（小说简介优先、历史简介兜底），阵营按源数据「主效」映射（魏+西晋→蓝、蜀→红、吴→绿、东汉/群雄/在野/起义军/少数民族→白）。
- 场景同步缩放（S = √人数/300）：星区中心、散布半径、星体基准尺寸、相机初始距离/上限、拾取阈值、飞行距离全部乘 S——人数增减十倍观感不变。
- 高密度防过曝：单星亮度 × (300/n)^0.32 密度补偿；群雄白色额外 ×0.5（加色混合三通道全占最易糊）。
- 星点贴图辉光收窄（核心更实、外沿更快衰减），近看星团内部不再糊成球，远景光晕由 Bloom 补回。
- 选中反馈从发光光斑改为势力色屏幕恒定圆环（随相机距离缩放 + 呼吸），解决点开大星糊半屏的问题。
- IAB 调试备忘：内嵌浏览器对 CSS 缓存激进，改动不生效时给 link 加 `?v=N`；对部分按钮 Playwright/CUA 点击派发不稳定，`dom_cua.click({node_id})` 可靠。

## 2026-08-29 · 里程碑 4.6：关系网全量化 + 背景锐化

- 用户反馈：关系网只有 54 条太单薄；背景发虚。
- 关系网：从源数据父亲(1357)/配偶(337)/兄弟(905)列自动生成血缘网，清洗 `[备注]` 后缀、按性别定「父子/父女」、pair 去重 → **54 手工 + 2926 自动 = 2980 条**。`import-relations.mjs` 幂等可重跑，自动边带 `auto` 标记。
- 度数分离：星体大小看总度数（家族Hub也大），**金晕只看剧情度**（手工线），避免曹氏家族刷掉刘备关羽的地标位。
- 面板关系列表截断至 12 条 + 「另有 N 条」（曹操 59 条不刷屏）；线透明度随可见边数自适应（0.4/0.3/0.2/0.12 四档）。
- 背景虚化根因是 Bloom 半径：strength 0.55→0.45、radius 0.45→0.28、threshold 0.32→0.35，远景星点恢复锐利。
