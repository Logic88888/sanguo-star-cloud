# 三国星云

一张可漫游的三维星图：每位三国人物是一颗星星。拖拽旋转、滚轮缩放，点星读他的生平。

参考项目：[诗云 Poetry Cloud](https://shiyun.cohenjikan.com)（星=人物 的三国演绎版）。

## 快速开始

```bash
npm install
npm run dev      # 开发，默认 http://localhost:5173
npm run build    # 构建静态产物到 dist/
npm run preview  # 本地预览构建产物
```

纯前端静态站，无后端、无数据库。构建出的 `dist/` 可部署到任意静态托管（GitHub Pages、Nginx 等）。

## 目录结构

```
├── index.html            # 页面骨架（标题 / 筛选栏 / 搜索框 / 面板）
├── src/
│   ├── main.js           # 3D 场景、拾取、相机飞行、关系连线、UI 交互
│   └── style.css         # 深色星空主题样式
├── data/
│   ├── characters.json   # 人物数据（一人一条，4530 人，简介全覆盖）
│   ├── relations.json    # 人物关系（2980 条：手工剧情线 + 自动血缘网）
│   ├── part*.json        # 分批生成的骨架名单（溯源用，可删）
│   ├── bios-*.json       # 分阵营撰写的生平简介（溯源用，可删）
│   └── ...
└── scripts/
    ├── merge-skeleton.mjs # 把 part*.json 合并进 characters.json
    ├── fix-roster.mjs     # 名单纠错与补漏（一次性）
    └── fill-bios.mjs      # 把 bios-*.json 按姓名填回 characters.json
```

## 人物数据格式

`data/characters.json` 是数组，每条字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| `id` | 唯一数字 | `1` |
| `name` | 姓名（必填，用于星位与搜索） | `"诸葛亮"` |
| `courtesy` | 表字 | `"孔明"` |
| `title` | 爵位 / 官职 | `"武乡侯"` |
| `faction` | 势力：`wei` / `shu` / `wu` / `other` | `"shu"` |
| `role` | 定位 | `"军师"` |
| `years` | 生卒年 | `"181—234"` |
| `bio` | 生平简介（100~200 字，自撰） | `"琅琊阳都人……"` |
| `quote` | 经典名句（可选） | `"鞠躬尽瘁，死而后已。"` |
| `quoteSource` | 名句出处（可选） | `"《后出师表》"` |

### 如何加一个人

1. 在 `data/characters.json` 末尾追加一条（`id` 递增，`faction` 四选一）。
2. 刷新页面即可。星星位置由 `姓名+势力` 哈希确定性生成——**已有人物的星位不会移动**，新人自动落进所属势力的星区。

### 关系数据（连线）

`data/relations.json` 是数组，每条一条关系：

```json
{ "a": "曹操", "b": "袁绍", "type": "仇敌" }
```

- `a` / `b`：人物姓名（必须在 characters.json 中存在，否则忽略并告警）
- `type`：关系标签（桃园结义 / 君臣 / 仇敌 / 联盟 / 旧主 等，自由文本）
- 同阵营两人：连线为该阵营纯色；跨阵营：两端顶点各用本阵营色，沿线段自动渐变
- 连线越多的人物：对应星点越大、越亮（对数缩放）
- 选中某人时，与其相关的线保持全亮，其余变暗
- 势力筛选时，任一端点被筛掉的线自动隐藏
- 面板「关系」列表可点击跳转到对方

### 势力与颜色

| faction | 势力 | 颜色 |
|---|---|---|
| `wei` | 魏 | 蓝 `#5aa7ff` |
| `shu` | 蜀 | 红 `#ff5c5c` |
| `wu` | 吴 | 绿 `#3ddc84` |
| `other` | 群雄 / 其他 | 白 `#f2f2f2` |

势力归属口径：以《三国演义》中归属时间最长 / 主要舞台为准；未进入三方的归 `other`。

## 已实现功能

- 3D 星云（Three.js）：主星按势力分四区，背景装饰星，自动缓旋（首次拖拽后停止）
- 人物关系连线：跨阵营双色渐变、同阵营纯色；筛选/选中联动
- 星点按关系数量缩放：连线越多越大越亮
- 悬停：星星高亮 + 姓名提示
- 点星：镜头飞向该星，右侧滑出人物面板（字 / 定位 / 爵位 / 生卒 / 生平 / 名句 / 关系列表，关系可点击跳转）
- 搜索：按姓名 / 字 / 称号模糊匹配，下拉候选，回车或点选定位
- 势力筛选：全部 / 魏 / 蜀 / 吴 / 群雄；搜索候选受当前筛选约束
